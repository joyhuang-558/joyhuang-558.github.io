讨论 · 安全

安全：leaking 与联网

(a) Leaking 防护

  • 只把 A 的轨迹拷进沙箱
  • run_candidate 只对 A 放行
  • B、C 从不拷
  • gold 答案给，gold 轨迹不给

→ B 被使用、但对 evolver 不可见。

(b) 联网

ablation 给 GLM 开联网：79 条命令里 0 次 curl。

零收益 + guardrail 难做（prompt injection / 外泄 / 不可复现）。

保持离线。既没损失（实测零收益），又省掉一整类安全 / 复现的麻烦。
